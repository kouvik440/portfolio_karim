# Cahier des charges personnalisable

## Objectif
Portfolio de développeur full-stack, pour présenter des réalisations et faciliter les prises de contact professionnelles. Le contenu est piloté par une interface d'administration React, reliée au backend Laravel.

## Direction visuelle souhaitée
- Moderne, distinctif, épuré ; responsive ; clair/sombre facultatif.
- Montrer le travail réel avant d'ajouter des animations.
- Définir une palette et une identité visuelle cohérente avant intégration.

## Parcours
- Visiteur : consulter l'accueil > voir projets > ouvrir fiche > consulter GitHub/demo > contact.
- Administrateur : se connecter > ajouter/modifier projet > téléverser images > publier > vérifier page publique.

## Livrables
- Site public ; dashboard privé ; base SQL ; gestion de médias ; tests automatisés ; README.
- Pages non implémentées, dépenses et dépendances documentées honnêtement.

## Personnalisation
Remplir `profil-exemple.md` : nom public, titre, courte biographie, compétences, vrais projets, URLs, images, CV et coordonnées qu'on souhaite réellement publier.

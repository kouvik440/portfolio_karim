# Prompt prêt à copier dans un agent de code

Utilise le skill `portfolio-laravel-react` de ce projet. Construis un portfolio personnel moderne, responsive et administrable avec Laravel + Inertia.js + React + TypeScript. Utilise le starter kit Laravel React et une base de données SQL existante. Le site public doit contenir accueil, à-propos, compétences, projets détaillés, parcours, CV et contact. L'administration privée sous `/admin` doit gérer tous ces contenus avec CRUD réel, publications/brouillons, uploads sécurisés et gestion des messages. Auth Laravel sécurisée ; aucune inscription publique non désirée. Concevoir une identité visuelle originale, sobre, accessible, avec animations légères et mode sombre si pertinent. Implémenter SEO indexable, tests backend, tests de responsive et instructions Windows/Laragon. Commence par analyser les fichiers existants ; ne réécris rien inutilement. Ne fabrique ni projets, ni liens, ni coordonnées personnelles. Termine par les commandes d'exécution, les tests réellement effectués et les fonctionnalités manquantes.
